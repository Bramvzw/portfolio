    Project 01 — Closed Beta

    Skylanders Tracker / 2026

    Ik verzamel zelf Skylanders, en de goede koopjes zijn snel weg. Vroeger ververste ik de hele dag Marktplaats en Vinted; nu doet deze app dat. Nieuwe advertenties komen vanzelf binnen, Claude leest ze en schat wat een figuur echt waard is. De backend, het AI-deel en de Android-app bouwde ik zelf.

    LaravelReact NativeClaudePostgres
    RoleSolo engineer
    UsersBackend + mobile
    StatusClosed beta on Play
    Problem
    Skylanders maakt sinds 2017 geen nieuwe figuren meer, dus alles gaat tweedehands. De zeldzame stukken zitten meestal verstopt in grote loten met een slordige titel en één wazige foto. Wie de goede koopjes wil, spit elke dag honderden advertenties door en moet er snel bij zijn. Dat kost uren, en je mist er alsnog.
    Solution
    Scrapers halen nieuwe advertenties van Marktplaats en Vinted binnen, rustig aan zodat de sites niet dichtslaan. Claude leest er elke advertentie: welke figuur, welke staat, en is de vraagprijs redelijk? Alleen de interessante blijven hangen. Daarnaast houd ik in de app mijn eigen collectie bij, met per stuk wat ik betaalde en wat het nu waard is. Eén Postgres-database eronder, gehost op Coolify.
    Result
    Draait als closed beta op Google Play. Ik bouwde alles zelf, van de scrapers tot de app. Wil je het proberen? Mail me voor beta-toegang, of download de APK direct.

    Project 02 — In daily use

    Smart Home Hub / 2025

    The dashboard on a Raspberry Pi in my living room. It controls the lights and Spotify, plans my week around my calendar, tracks prices and turns supermarket offers into a weekly menu. Every morning it writes a short briefing from all of that.

    LaravelLivewireClaudeDocker
    RoleSolo engineer
    UsersMy household
    StatusOpen source · MIT
    Problem
    Self-hosted dashboards like Homepage or Dashy are mostly tiles with links. I wanted one that does things, and where the parts know about each other: rain in the forecast should change the lights, and a deal I track should show up in the weekly menu.
    Solution
    A modular monolith: twelve Laravel modules (weather, calendar, lighting, Spotify, deals, recipes and more) on top of a shared set of contracts. Each module can contribute to the morning briefing, which Claude writes via Prism. Without an API key a fixed template takes over. Lamps, shops and concert sources are adapters behind an interface, so a new brand is one class.
    Result
    Runs in Docker on my Synology NAS, with a Raspberry Pi as the screen. 217 commits since May 2025, with tests per module and CI on GitHub.
    View the source github.com/Bramvzw/smart-home-hub
    Project 03 — v0.1 released

    sooth / 2026

    A command-line tool that runs your existing test command and tells you which tests are flaky. It keeps a history per commit, so a test that both passed and failed on the same code is proven flaky, not guessed. My first project in Rust.

    RustJUnit XMLCLI
    RoleSolo engineer
    UsersDevelopers
    StatusOn crates.io
    Problem
    A flaky test blocks you: the pipeline goes red, you re-run it, it turns green, and you still don't know whether the test is unreliable or something is really broken. Tools that track this, like ReportPortal or Allure, need a server and a dashboard.
    Solution
    sooth wraps the test command you already have and reads the JUnit report it writes. Each run adds one line per test to a local history file. With --verify it re-runs only the failed tests to tell real failures from flaky ones. It never hides a failure: the exit code stays what your test runner said. No server, no account, no AI.
    Result
    Version 0.1 is on crates.io, with presets for pytest, PHPUnit, Jest and Go. Detecting slow and order-dependent tests is next on the roadmap.
    View the source github.com/Bramvzw/sooth cargo install sooth crates.io
